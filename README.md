# ポイント手帳（V1.4）

複数のポイントサービスの残高、獲得・利用履歴、失効予定をブラウザ内で管理するWebアプリです。HTML / CSS / JavaScript の単一ページで動作します。

## 使い方

1. 「サービスを追加」から管理したいポイントサービスを登録し、初期残高とその基準日を入力します。
2. 各サービスの「詳細・記録を開く」から獲得・利用や残高修正を登録します。「獲得元」にはカード・店舗・サイト名などを任意で登録できます。
3. 獲得したポイントに有効期限があれば日付を入力するか、手動で失効予定ポイント数・有効期限を登録します。
4. 「ホーム」で残高と30日／60日以内の失効予定、「ポイント履歴」で記録、「月別獲得」で月ごとの獲得ポイントを確認します。

## V1.4 での変更

- **月別獲得のスマートフォン表示：** 1〜12月を横一列に固定し、画面幅に収まらない場合は左右のスワイプで閲覧できます。以前のように2列で縦長に並ぶことはありません。
- 計算ロジックと保存先（`point-techo-v4`）に変更はありません。これまでの利用記録は引き続き保持されます。

## V1.3 での変更

- **利用日の順序で再計算：** 利用記録を後から入力しても、記録した日付（同日は登録順）を基準に、当時獲得済みの期限付きポイントから、期限の早い順に差し引きます。獲得が利用より後の日付なら、その利用分を当該獲得ポイントには充当しません。
- **手動で登録する期限数量：** 登録・修正時点の残数のスナップショットです。登録以前の日付の利用を重複して差し引きません。
- **初期残高：** 基準日以前の獲得・利用は履歴に残りますが、現在の残高と失効予定に重複計上しません。基準日以前から保有する期限付きポイントは、公式画面を確認してサービス詳細から登録できます。
- **ポイント履歴：** 新しい日付から順に表示。初期表示は全期間です。月やサービス、種類で絞り込めます。
- **期限経過・要確認：** 登録された有効期限を過ぎ、記録上まだ残数がある場合はホームに「期限経過・要確認」を表示します。期限が過ぎても現在の残高を自動的には減らしません。公式サービスで実際の残高を確認後、残高修正・失効予定の編集をしてください。

## 計算上の注意

- 利用時に有効期限が早いポイントから充当するのは**本アプリの簡易計算ルール**です。実際の消費順、期限延長、通常ポイントと期間限定ポイントの取り扱いはサービスによって異なります。公式画面を正とし、必要に応じて修正してください。
- 手動で有効期限のみ登録しても、残高は増えません。
- 同じポイントを複数のサービス名で重複登録しないよう、ポイントの帰属先ごとに管理してください。

## データとプライバシー

データは各利用者のブラウザの `localStorage` に保存します。サーバー送信や他ユーザーとの同期はありません。同一ブラウザ・同一オリジンの V1.1 / V1.2 と保存場所を共通にしているため、以前の登録内容を引き継ぎます。ブラウザデータ削除時に記録が失われる可能性があるため、「設定」の JSON バックアップ保存を推奨します。

## 公開

`index.html` と `README.md` を GitHub リポジトリのルートに配置し、Settings → Pages → Deploy from a branch → main → / (root) で公開できます。
